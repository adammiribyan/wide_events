# Security policy

Report vulnerabilities privately via
[GitHub security advisories](https://github.com/adammiribyan/wide_events/security/advisories/new);
please don't open a public issue for anything exploitable. You'll get a
response within a week.

The latest release line receives security fixes. The gem handles telemetry
attribute data; if you find a way to make it leak values it shouldn't, raise
into application code, or execute anything from attribute contents, that's in
scope.
